# MermaidTail

MermaidTail is a custom Minecraft Bedrock addon that replaces the player's legs with a realistic mermaid tail. The addon includes a high-definition texture with four color variants: Aqua Blue, Ruby Red, Emerald Green, and Obsidian Black. The tail automatically changes its behavior based on the player's environment, triggering a crawling animation on land and a swimming animation in water. The model is designed to seamlessly attach to the standard Minecraft player skin torso, ensuring a perfect fit.

## Install

1. Download the addon from the GitHub repository or the EnderDevelopment marketplace.
2. Extract the downloaded zip file.
3. Move the extracted folder to the `com.mojang` folder in your Minecraft Bedrock Edition game files.
4. Launch Minecraft Bedrock Edition and enable the addon in the settings.

## Use

1. Equip the custom "custom:mermaid_tail" armor item.
2. On land, the player will automatically crawl with a low creeping animation.
3. In water, the player will swim with a smooth swimming animation.
